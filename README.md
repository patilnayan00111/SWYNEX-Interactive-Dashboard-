# SWYNEX Interactive Dashboard


## Project Overview
This project was completed as part of the SWYNEX Technologies Data Analyst Internship – Task 3. An interactive Power BI dashboard was created using the Student Performance in Exams dataset.

## Tools Used
- Power BI Desktop
- Microsoft Excel / CSV dataset

## Dashboard Features
- Total Students KPI
- Average Math Score KPI
- Average Reading Score KPI
- Average Writing Score KPI
- Gender-wise Average Math Score chart
- Test Preparation vs Average Scores chart
- Lunch Type vs Average Scores chart
- Interactive slicers for Gender, Lunch Type, and Test Preparation

## Key Insights
- The dataset contains 1,000 student records.
- Average Math Score: 66.09
- Average Reading Score: 69.17
- Average Writing Score: 68.05
- Students who completed test preparation achieved higher average scores across all three subjects.
- Students with standard lunch had higher average scores than students with free/reduced lunch.

## Project File
`SWYNEX_Student_Performance_Dashboard.pbix`

## How to Use
Download the PBIX file and open it using Power BI Desktop. Use the slicers to explore the dashboard interactively.
